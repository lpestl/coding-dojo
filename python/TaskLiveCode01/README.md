# Test Live Code 01 — Find problem (разберись в чужом коде и найди зависание)

## О задании

Это задание выполняется в режиме **LiveCode**: вы смотрите на чужой код, рассуждаете
вслух и на глазах у интервьюера разбираетесь, что в нём происходит, находите проблему
и исправляете её.

Код, с которым предстоит работать, находится в файле
[`main.py`](main.py).

## Что нужно сделать

1. **Разобраться в чужом коде** и объяснить, что он делает:
   - какие сущности есть в коде (классы, функции, глобальное состояние);
   - как они взаимодействуют между собой;
   - каков ожидаемый сценарий работы программы.

2. **Найти проблему**, из-за которой программа зависает (не завершает свою основную
   работу и выводит сообщение о заморозке).

3. **Объяснить причину** зависания — что именно идёт не так и почему.

4. **Исправить код** так, чтобы он работал корректно, без зависания.

5. **На каждом шаге рассуждать вслух** — проговаривать ход мыслей, а не просто
   показывать готовый результат.

## Формат выполнения

- Работа ведётся в редакторе, с живым запуском программы (`python main.py`).
- Сначала — чтение и устное объяснение кода, затем — диагностика, затем — исправление.
- Исправление должно быть минимальным и обоснованным: объясните, почему именно это
  изменение устраняет проблему.

## Критерии оценки

- Умение читать и объяснять чужой код.
- Понимание того, как работает `asyncio`, задачи и разделяемое состояние.
- Умение рассуждать о причине зависания, а не угадывать.
- Аккуратность и минимальность исправления.
- Умение аргументировать принятое решение.
